# Bangladesh Travel Super App — frontend

Responsive React + TypeScript + Vite MVP for deshgo. Includes local mock content and functional client-side flows for home, explore, destination details, AI planner, visual guide, translator, booking, trip, profile, and safety.

## Run locally

```bash
npm install
npm run dev
```

The interface uses Tailwind utility classes, Lucide React icons, remote travel imagery, and no external API or payment integration.
